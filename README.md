# LessTap for Android

This repository holds the LessTap Android app's installable files (APKs) only. There is no source code here.

LessTap is an offline digital wellbeing app: honest screen time, respectful app blocking and cleanup of unused apps. Everything it records stays on your phone.

## Install

1. On your Android phone, open the [latest release](../../releases/latest).
2. Download the `LessTap-<version>.apk` file and open it.
3. If Android asks, allow your browser or file manager to install apps, then tap **Install**.

## Updates

Once installed, LessTap checks this page every time it opens and offers each new version inside the app. Tap **Update now**, then confirm once when Android asks. Your history and settings stay as they are.

Each release lists the APK's SHA-256 checksum. LessTap checks it before installing, and you can check a file you downloaded yourself.
